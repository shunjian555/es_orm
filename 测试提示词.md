你现在需要为当前已经开发完成的 PHP Elasticsearch ORM 扩展包，建立一套完整、专业、可长期维护的 PHPUnit 自动化测试体系。

重要：

这个组件已经开发完成并且已经安装到当前项目中。

不要重新设计 ORM。

不要重写现有业务代码。

不要为了通过测试而随意修改生产代码。

你的主要任务是：

「分析现有组件 API → 设计测试矩阵 → 编写 PHPUnit 测试 → 执行测试 → 分析失败原因 → 修复测试 → 最终确保测试稳定通过」。
